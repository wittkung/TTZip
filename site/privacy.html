TTZip 隐私政策 (Privacy Policy)

最后更新生效日期：2026年8月18日

1. 核心隐私承诺

TTZip 是一款完全运行在您本地 Mac 计算机上的原生工具软件。我们坚信用户的隐私权不可侵犯，因此 TTZip 遵循“零数据收集、零网络回传、零行为追踪”的最高隐私准则。

2. 数据收集与处理

  • 无个人信息收集：TTZip 不收集您的姓名、电子邮箱、IP 地址、设备标识符或任何个人身份信息。
  • 无文件内容上传：您压缩、解压或预览的所有文件、文件夹内容及其元数据，全部在您本地内存与磁盘中以 100% 进程内 C 引擎处理，绝不经过任何外部服务器。
  • 无第三方 SDK 追踪：Mac App Store 版本的 TTZip 移除了所有第三方统计与分析 SDK。

3. 系统权限使用说明

为了执行归档与解压操作，TTZip 在 macOS App Sandbox 沙盒规范下请求以下最小必要权限：

  • 用户选择的文件读写权限 (User-Selected Files)：仅在您主动拖拽文件或在文件对话框中选定文件/保存目录时，授予 TTZip 访问该特定文件的权限。
  • 安全作用域书签 (Security-Scoped Bookmarks)：用于在您允许的情况下持久保存最近访问的归档路径，避免重复授权。
  • 文件时间戳 API (File Timestamp)：仅用于在打包或解包时读取与恢复文件的原始修改与创建时间戳。

4. 密码保险箱安全性

您保存在密码保险箱中的解压密码均采用硬件级 AES-256 加密与 PBKDF2-SHA256 派生存储于您本地的 Keychain 与安全存储区。密码在内存使用完毕后均通过 volatile 指针执行物理强制清零（防 Dead-Store 消除），绝无泄露风险。

5. 联系我们

如果您对本隐私政策有任何疑问或建议，欢迎通过 GitHub 提交反馈：TTZip GitHub Issues。
